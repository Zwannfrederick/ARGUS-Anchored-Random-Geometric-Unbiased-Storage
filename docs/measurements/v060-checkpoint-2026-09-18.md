## Hypotheses

| Hypothesis | Verdict | Evidence |
|---|---|---|
| Write-frontier pages keep policy-on off the fast path | confirmed | census: one cold run per tensor, exactly the rewritten pages |
| `access_count >= 2` threshold is the cause | refuted for warm requests | warm cold pages have counts ≥ 16; contributes only at cold start |
| Budget/alignment/codec rejects | refuted | zero in every run |
| Wave quantization (52 registers, 1.24 waves) | confirmed, secondary | 1.27x at fixed kernel; the D-generic slot structure was 2.10x |
| Per-element pointer→branch→generic-load chain dominates | weakened | 9 → 5 serial memory ops gave −9% kernel time |
| Scalar resident kernel is now instruction-issue dominated | supported, not measured | ~3.6e11 dynamic warp instructions (133-instruction loop per cell) over 3.63 s at ~1.9 GHz busy clock ≈ 64–68% of 80 schedulers' issue slots |
| Payload D2D was the main staged cost | refuted earlier and again | policy-on D2D → 0 together with launch batching |

Nsight Compute could not be used: `RmProfilingAdminOnly=1` in the NVIDIA driver restricts
GPU performance counters to root. Issue utilization above is an estimate from SASS
instruction counts, CUDA-event kernel time and sampled SM clock, not a counter.

## Where the time is now (profiled attribution; not mixed with the medians)

which is outside the attention datapath.

## Decision for the next kernel step (not started)

- (A) Next-cell register prefetch: **not recommended**. It adds instructions to a loop
  that already spends ~2/3 of issue slots, and shortening the memory chain returned only 9%.
- (B) Shared-memory K/V tile reuse: **not first**. It removes about four load
  instructions per cell out of ~133; there is no counter evidence of an L2 bandwidth limit.
- (C) Lane-per-cell exact tile kernel: **recommended**. Each lane scores its own cell with
  the unchanged stride-halving tree. The running max is an exact prefix scan, α/β are
  deterministic per lane, and the `sum`/`acc` FFMA chains keep cell order. This removes
  the per-cell 5+2 shuffles, the lane-0 divergent softmax and most of the per-cell
  address arithmetic. Category 2: parity must stay exact and every contraction checked
  in SASS.

Stop conditions stay as reported in the research phase. Attention is still the largest
single term in GPU-control (≈66% of profiled prefill). A perfect attention kernel would
leave GPU-control at roughly 1.6–1.9 s, about 1.2–1.4x stock-host, because of the
non-attention path.
